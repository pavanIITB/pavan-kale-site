Hand someone the product the way they would normally receive it. If it comes in a box with instructions, give them the box. If it normally sits on a desk, put it where it would sit. A careful setup gives you evidence about the actual experience.

Ask them to start with a concrete task, then leave room for silence. Record the first place they pause, what they look at, and whether they try the same action more than once. When they’re finished, ask what they thought would happen when they took that step. That question can tell you more about the design than a general rating.

Run the same task with a few people before changing everything. If more than one person misses the same cue, try altering that cue alone. A new first-use test can tell you whether the fix helped or whether something more fundamental is getting in the way.

## Decide what to change after watching

After several sessions, read the observations before proposing fixes. Put the points where people hesitated in the order they happened. If a misunderstanding near the start led to three later problems, fixing that first one might matter more than redesigning the entire sequence.

Try making the smallest change that gives the person a clearer next step. Then ask someone new to attempt the same task. Keep the instructions and setting comparable so you know what changed. A test where somebody recovers more easily can be useful even if they still hesitate, because it tells you which part of the design is already giving them a way forward.
